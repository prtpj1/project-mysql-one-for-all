## Project Description
In this BackEnd project, I put into practice a bit more of what I learned about MySQL.

## In this project, I learned and put into practice
- Normalize a non-normalized table
- Create queries to find the requested information (listed below)

## According to the project requirements designated by Trybe, I learned how to
- ✅ Normalize the tables to the 3rd Normal Form
- ✅ Display music statistics
- ✅ Display the playback history for each user
- ✅ Display the user's status if they are active or inactive
- ✅ Display the top 2 hits currently playing
- ✅ Display the company's revenue report
- ✅ Display a list of all albums produced by each artist
- ✅ Display a list of albums produced by the artist Walter Phoenix
- ❌ Display the number of songs currently present in the playback history of user Bill
- ❌ Display the name and the number of times each song was played by users of the free or personal plan
- ❌ Display song names in their normal form and with the string changed

_*NOTE: In some projects, some requirements were not completed due to the accelerated dynamics of the course and not because I didn't know how to do them. At the time, I just needed a little more time.*_

_*I have not yet decided whether it is better to leave it this way to demonstrate my progress during my learning or if it would be better to complete the missing requirements in the course projects.*_

_*Feedback is welcome.*_

## How to run the application?
- MySQL needs to be running on your machine
- ⚠️ If you are on Windows, stop MySQL for Windows
- Clone the repository: <br>
`git clone git@github.com:prtpj1/project-mysql-one-for-all.git`
- Access the project folder: <br>
`cd project-mysql-one-for-all`
- Install the dependencies: <br>
`npm install`
- Open VS Code: <br>
`code .` <br>
- Execute the queries from each challenge file in the project folder within VSCode itself if you use a DB extension like **"Database"**, or in a Database Management program like **"MySQL Workbench"**
